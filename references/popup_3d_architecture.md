# 3D 纸艺零穿模安全走廊、Apple 极简规范与双主题互动指标

本技能生成的所有单文件 `.html` 立体贺卡统一锁定在 `resources/card_shell_template.html` 母版引擎之上，确保无论是哪家 AI Agent 调用、使用哪类生图模型生成的任意长宽比素材，最终成品都能 **0 穿模、0 报错、100% 保持一致的 Apple 极简纸艺质感**。

## 一、 全 Agent 通用“4 层零穿模安全走廊”架构

为从底层根治不同 Agent 生成的图片在 3D 翻开途中或极限拖拽时出现的穿模、劈穿底页或左右重叠问题，引擎与裁图脚本双重锁定以下 6 条物理法则：

1. **后端按距保护去杂点（`scripts/process_diecut.py`）**：
   - 改进版 `remove_small_components()` 结合连通域面积和到主主体包围盒的距离清理杂点：远离主体的四角噪点/孤立圆点坚决清除（包括已带透明背景 PNG 的角落碎点），贴近主体的 3px 细蜡烛芯、小花瓣等精细特征予以保护；
   - 打包阶段通过 `validate_standee_visibility()` 严查有效主体面积占比，直接拦截全白或全透明无效图。
2. **纸页微折角 + 坐标系贴合（杜绝纸页切穿道具）**：
   - **左右横版**：单页 `430px × 540px`（展开 `860px × 540px`），左右纸页最终微折 `±3.5°`；左前道具实时跟随左页旋转角并贴合左页平面 `+10px` 之上，右前火漆信封紧贴右页平面 `+10px` 之上，后景拱门按原图比例缩放并动态抬高至 `Z = (archW / 2) * max(sinA, sinL) + 14px`。
   - **上下翻折版（标准 4:3 横向长方形）**：单页 `560px × 420px`（标准 4:3 横向长方形封面），向上掀开后成为 `560px × 840px`（2:3 宽敞双页）；上页掀至最终夹角 `-26°` 作为背景立面，下页平展承托，花环拱门严格按原图等比缩放立在折线正前方安全走廊（`translate3d(0px, 14px, 10px)` 搭配 `-68°` 倾角，与 `-26°` 上页之间保留充足正前净空），左前道具、中央人物与右前火漆信封横向舒展排开。
3. **两段式零穿模翻页曲线（全程 0% ~ 100% 无中间帧劈穿）**：
   - **阶段 1（`openProgress ∈ [0, 0.56]`）**：两页纸面率先顺滑完成翻折并稳稳停靠在安全展开角（横版 `±3.5°`、上下 4:3 版上页 `-26°`）；此时所有立体部件保持隐藏 (`openProgress < 0.58`)，彻底避免半开途中被左页或上页劈穿。
   - **阶段 2（`openProgress ∈ [0.58, 1.0]`）**：纸页完全停稳后，4 层立体件在各自已算好净空的安全立面倾角（`-68° / -70° / -64°`）之上以 `scaleY(rise)` 沿底座折痕平滑长高展开，从数学空间上确保整个展开过程中立体件与纸页交点精确为 `0`。
4. **全正向 Z 厚度堆叠（零负 Z）**：
   - 3 层卡纸背衬全部按 `0px / +1.2px / +2.4px` 正向朝前叠加，纸片背后绝不会向后捅穿底页。
5. **动态等比防撞排布与透视安全缩放**：
   - `computeSafeLayout()` 对花环拱门、中央人物与左前道具统一保持真实像素等比缩放，并根据实际宽高动态拉开横向避让距离；
   - `updateScale()` 计入 3D 透视近端放大系数与旋转留白（窄屏 `<= 520px` 自动限幅倾角），确保 `390×844` 与 `375×667` 手机竖屏正面及拖拽下左右均不裁边。

## 二、 Apple 三大设计原则、零 Emoji 与移动端编辑保护

1. **清晰（Clarity）**：不放遮挡插画的多余浮窗提示，通过实体左前道具（生日跳动烛火蛋糕 / 圣诞常亮闪烁星星灯树）与右前红色火漆迷你信封直接引导交互。
2. **克制（Deference / Less is More）**：顶部胶囊展开即隐去；底部唯一居中单行磨砂控制栏（`overflow: hidden`，禁止滚动条），仅保留 4 个核心按钮（生日 `合上 | 八音盒 | 吹蜡烛 | 祝福信`，圣诞 `合上 | 八音盒 | 星灯 | 祝福信`，旋转后按需出现回正按钮）；**全程零 Emoji**。
3. **手机端原生上下滚动编辑弹窗 + 独立存储隔离**：每张贺卡具备唯一 `cardId` 隔离本地 `localStorage`（同域名多卡互不串文）；整个弹窗遮罩开启原生上下滚动（`overflow-y: auto; -webkit-overflow-scrolling: touch; touch-action: pan-y`），窄屏打开“修改祝福语”时隐藏预览直达表单，输入框采用 `16px` 防 iOS 自动缩放并在聚焦时自动 `scrollIntoView` 滚入视口中央，确保软键盘弹起后依然可以顺畅上下滑动并点击底部“保存”按钮；正文字号按行数与总字数自动微缩档位。

## 三、 双节日声学、圣诞星灯探测与互动规范

1. **生日模式（`occasion: "birthday"`）**：
   - **手机 50% 音量饱满防破音八音盒**：Web Audio 合成三层温暖谐波（主基波 `0.78` + 三角波二倍八度泛音 `0.26` + 钢齿三倍泛音 `0.15`），串接 `DynamicsCompressorNode`（`-12dB / 8:1`）防破音限幅器、`0.78` 主增益与 `0.84` 后级峰值安全余量增益（稳定留出约 `-1.5 ~ -2 dBFS` 安全余量），且吹气仿真音效同样接入同一压缩限幅总线，保证满音量混音也 0 削波、0 破音，全程音量一致不骤降。
   - **翻开前预授权（5 秒防卡死）+ 老访客零等待重开 + 宽带气流防误灭 + 1 秒零报错兜底**：
     - 首次在生日模式点击封面准备翻开时，先同步唤醒共用 `AudioContext` 并保持卡片合上不动，优先弹出麦克风授权框（内置 `5000ms` 超时保护，防止内置浏览器无响应卡死）；授权结束或超时后再完整翻开贺卡并从头播放八音盒；
     - 一旦本页此前已成功获得麦克风许可（`micPermissionGranted`），合卡后再点翻开时零等待立刻播放展开动画，并在后台异步重连音轨；
     - 配置递增 `micSessionId` 会话编号与并发锁，快开快合或超时迟到返回的旧音轨立即关停释放；用户拒权（`NotAllowedError`）后记录状态绝不重问；
     - 串接 `GainNode(3.2)` 软件增益 + `1024` 点高精度 FFT，按设备真实 `sampleRate` 划分频段，以 `70~680Hz` 宽带连续活跃度与低频主导平坦度算法（`activeRatio >= 0.38`, `top2LinRatio <= 0.68`, `lowAvg >= midAvg * 0.92`, `lowAvg >= highAvg * 1.15`）识别真实吹气气流，隔离高响度八音盒、180Hz 嗡声与 440Hz 单音；
     - 非 HTTPS 附件或无权环境下静默零报错，无缝由“轻点直灭 + 长按约 `1.0s`（`140ms + 860ms`）仿真吹气”兜底。
   - **刺绣信笺**：内联可见像素无损（VP8L 无损封装）WebP 真毛边棉麻底布 `resources/embroidery_linen.webp`（严格禁止圣诞模式误用）；超长正文自动开启布面内部上下滑动，绝不越出布面毛边。

2. **圣诞模式（`occasion: "christmas"`）**：
   - **机械八音盒**：同款手机高响度三层谐波音色演奏《We Wish You a Merry Christmas》。
   - **Alpha 内芯实心校验圣诞星灯（兼容白雪树与分叉树）**：
     - 命令行可独立调用：
       ```bash
       python scripts/process_diecut.py diecut --input work/tree_raw.png --output work/tree_standee.png --detect-tree-lights
       ```
     - `detect_tree_light_anchors()` 基于 Alpha 实体掩码向内腐蚀剥除刀模纸边得到树冠实心内芯，精准将顶星钉在树尖中心，再按高度层扫描连续实心枝干区间（跳过分叉空隙），逐点验证 `5×5` 像素均位于实心内芯；窄树或严重分叉树自动减少灯数，确保 **0 悬空**。
   - **圣诞刺绣信笺**：仅使用无损 WebP 空白真毛边棉麻底布 `resources/embroidery_linen_blank.webp`（缺失时安全降级纯矢量圣诞棉麻底板，绝不回退生日底布）叠加圣诞树绣图与 `MERRY ~ CHRISTMAS !`，全程零“生日”穿帮。
