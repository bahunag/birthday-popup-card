# 3D 纸艺零穿模安全走廊、Apple 极简规范与双主题互动指标

本技能生成的所有单文件 `.html` 立体贺卡统一锁定在 `resources/card_shell_template.html` 母版引擎之上，确保无论是哪家 AI Agent 调用、使用哪类生图模型生成的任意长宽比素材，最终成品都能 **0 穿模、0 报错、100% 保持一致的 Apple 极简纸艺质感**。

## 一、 全 Agent 通用“4 层零穿模安全走廊”架构

为从底层根治不同 Agent 生成的图片在 3D 翻开或旋转时出现的穿模、劈穿底页或左右重叠问题，引擎与裁图脚本双重锁定以下 5 条物理法则：

1. **后端去孤立碎点 + 纯净刀模边界（`scripts/process_diecut.py`）**：
   - 自动执行 `remove_small_components()` 清除 AI 生成白底图边缘残留的零散小雪点/水彩飞沫，防止真实包围盒被拉偏导致坐标算歪或压出大块多余白边。
2. **纸页微折角 + 坐标系贴合（杜绝纸页切穿道具）**：
   - **左右横版**：单页 `430px × 540px`（展开 `860px × 540px`），左右页轻微内收 `±3.5°`（仅抬起 13px）；左前道具直接挂在左页坐标系、右前信封直接挂在右页坐标系，天然贴合各自纸面零悬空、零穿底；后景拱门按自身宽度动态抬高至 `Z = (archW / 2) * sin(3.5°) + 8px`，彻底避免被左右内页边缘切到。
   - **上下翻折版（全新 4:3 横向长方形）**：单页 `560px × 420px`（标准 4:3 横向长方形封面），向上掀开后成为 `560px × 840px`（2:3 宽敞双页）；上页微收 `5°` 后倾立起作为背景墙，下页平展作为宽阔舞台，拱门立在折线正前方安全区，左前道具、中央人物、右前火漆信封横向舒展排开。
3. **翻越 90° 门控防劈穿动画**：
   - 封面翻开进度 `p < 0.48`（横版）或 `p < 0.46`（上下版）时，所有立体件保持伏贴隐藏；封面越过 90° 垂直中线后再丝滑立起，从物理上杜绝翻转纸页像刀片一样劈穿人物与拱门。
4. **全正向 Z 厚度堆叠（零负 Z）**：
   - 取消旧版负值 `translateZ(-3px/-4px)` 背衬与向后斜撑；3 层卡纸厚度改为 `0px / +1.2px / +2.4px` 正向朝前叠加，纸片背后绝不会向后捅穿底页。
5. **动态宽度防撞排布算法（`computeSafeLayout()`）**：
   - 前端读取每张裁切图的真实宽高，自动计算并保证左前道具、中央人物与右前火漆信封之间的横向安全间隙（不重叠、不出界），彻底免疫不同生图模型画胖画瘦带来的撞车穿模。

## 二、 Apple 三大设计原则与零 Emoji 红线

1. **清晰（Clarity）**：不堆砌遮挡插画的悬浮气泡提示，通过实体左前道具（生日跳动烛火蛋糕 / 圣诞常亮闪烁星星灯树）与右前红色火漆迷你信封直接引导轻触互动。
2. **克制（Deference / Less is More）**：
   - 贺卡展开后顶部胶囊自动隐去，专注沉浸欣赏；
   - 底部唯一居中单行磨砂控制栏（`overflow: hidden`，严禁滚动条），仅保留 4 个核心按钮：
     - 生日模式：`合上 | 八音盒 | 吹蜡烛 | 祝福信`（旋转视角后按需出现 `回正`）；
     - 圣诞模式：`合上 | 八音盒 | 星灯 | 祝福信`（旋转视角后按需出现 `回正`）；
   - **全程零 Emoji 表情包**：全部图标采用 `1.6px` 圆角精细纯矢量 SVG。
3. **深度（Depth）**：真实 300g 米白厚卡纸切边、纸面接触影、多角度拖拽欣赏（兼容桌面鼠标、手机触屏与 Safari 3D 渲染层）。

## 三、 双节日声学与互动规范

1. **生日模式（`occasion: "birthday"`）**：
   - **机械八音盒**：Web Audio 合成温柔 C/F 大调《生日快乐歌》，带木盒低通共鸣。
   - **翻开自动请求高灵敏度麦克风 + 零报错轻点/长按兜底**：
     - 用户点击翻开贺卡的同一瞬同步创建并唤醒 `AudioContext`（避免 iPhone Safari 音频上下文被冻结返回全 0）；
     - 在 `https://` 或 `localhost` 安全环境下自动发起一次麦克风授权请求，串接 `GainNode(3.5)` 放大微弱吹气并结合 50~450Hz 低频气流能量判断，配合顶部极简微细气流感应条让手机轻吹即可灵敏灭烛；
     - 在用户拒绝授权、手机无权限弹窗或微信直接打开本地 HTML 附件等非安全上下文下，**绝不弹出任何报错提示**，自动由“轻点直灭 + 长按约 1 秒仿真吹气（带风声、火苗摇曳与漫天花瓣）”无缝兜底。
   - **刺绣信笺**：内联真毛边棉麻底布 `resources/embroidery_linen.png`（带 `HAPPY ~ BIRTHDAY !` 手工刺绣小蛋糕头图）。

2. **圣诞模式（`occasion: "christmas"`）**：
   - **机械八音盒**：自动切换为温暖清脆的《We Wish You a Merry Christmas》经典圣诞八音盒旋律。
   - **常亮闪烁星星灯圣诞树**：`process_diecut.py --detect-tree-lights` 自动扫描树冠真实绿叶区生成树顶金星 + 13 颗树冠内部锚点；网页加载即自动常亮并呈现柔和错落闪烁的暖金/香槟/暖白星光光晕；点击圣诞树或底部“星灯”按钮可触发星灯璀璨绽放并飘落冬日雪花与暖金彩屑。
   - **圣诞棉麻刺绣信笺**：自动切换为空白真毛边棉麻底布 `resources/embroidery_linen_blank.png`，顶部叠加同款深炭棕棉线质感手绘刺绣小圣诞树与 `MERRY ~ CHRISTMAS !`，右前迷你信笺同步切换为圣诞小树与 `MERRY CHRISTMAS`，全程零“生日”穿帮元素。
