# 手绘 3D 立体弹出式节日贺卡 Skill (`birthday-popup-card` · V8.4 全闭环高保真版)

专为**自带看图与生图能力的多模态 AI 助手（千问、豆包、Antigravity 等）**打造的 3D 立体贺卡定制技能包，支持 **生日 / 圣诞双主题** 与 **上下翻折 4:3 横向长方形 / 左右横版双版式**。

## 设计目标与核心特点
- **精简纯文本结构，兼顾云端直装与严格品控**：仅包含 **7 个核心纯文本文件**（零外部二进制大图、零 Base64 密文、零联网脚本、零 API 密钥），保持快速安装与生图节奏的同时，内置高密度视觉拆解、“两版都做”双批流水线及严格防写真/缺烛芯拦截门禁。
- **暖沙原麻 3D 高度场棉麻刺绣信本地实时合成**：`scripts/pack_card.py` 在本地打包时用纯 Pillow 现场合成带 3px 斜粒微纹理、低频柔皱云斑、连续缝线凹沟、粗实不规则棉绳锁边及手撕短棉絮的亚麻底布（520×710，本机织造约 0.13 秒，WebP q=78 编码约 0.10 秒、合出约 82 KB 透明底图，完整重打包耗时约 1 秒出头），无需内置 1.46 MB 原图即呈现手绣布贴层次，并支持手机端滑动编辑与超长文滚动。
- **锁定正宗 3D 母版拼接输出与三频带吹蜡烛引擎**：
  - 两段式零穿模 3D 纸艺（纸页先翻平落位，4 层立体纸雕再沿折线长起，小屏拖拽无裁边）；
  - 三层谐波 + 防破音动态限幅 + 峰值安全余量机械八音盒（生日《生日快乐歌》/ 圣诞《We Wish You a Merry Christmas》）；
  - **三频带声学吹蜡烛引擎**（50~260Hz 轰鸣 / 90~650Hz 偏低呼气 / 1000~3600Hz 气声双通道、完整环境底噪校准与真实时间步长积分；在 Edge 数字音轨压测中已覆盖静音、180Hz/440Hz 纯音、人声模拟、八音盒全曲、开卡前后持续宽带风扇/道路干扰以及高通/偏低频/叠加八音盒吹气等场景；真机不同麦克风硬件距离与 App 内嵌容器仍建议实测确认）+ 可信度防纸边误判烛芯识别（无蜡烛自动隐藏火苗）；
  - 圣诞树 Alpha 实体内芯防悬空常亮闪烁星灯（含偏心歪斜树尖适配与无安全点隐藏）+ 点击星光绽放飘雪。
