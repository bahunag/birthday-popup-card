# 立体弹出式手绘节日贺卡生成 Skill (`birthday-popup-card`)

一个开箱即用、可放进任意支持 Agent Skill 的 AI 工具中运行的通用 **3D 立体贺卡定制技能包**，现已全面支持 **生日贺卡 / 圣诞贺卡双主题** 与 **左右横版 / 上下翻折 4:3 横向长方形双版式**！

只要把本 GitHub 仓库链接发给您的 AI 助手并说 **“帮我配置这个 Skill”**，配置完成之后，它会先和您确认主题与版式，并收集素材：
1. **节日主题**：生日贺卡 ／ 圣诞贺卡；
2. **贺卡版式**：上下翻折（标准 4:3 横向长方形矩形贺卡）／ 左右横版 ／ 两版都做；
3. **封面风格参考图**：任意喜欢的画风参考图（横图、竖图都不影响，后台自动提取画风并**重新绘制一张全新节日封面**，绝不直接贴原图）；
4. **中央主角真人照片**：保留五官、发型、衣服与神态动作，用封面同款画风重绘成立体手绘人物；
5. **祝福语（二选一）**：
   - **选项一（用现成模板）**：套用生日或圣诞专属模板，只需填抬头称呼、落款署名与可选的 1~2 句灵活心里话；
   - **选项二（自己写）**：直接发来或上传您自己写的完整祝福语。

随后 AI 助手会在后台自动完成**全套插画重绘 -> 纸艺刀模米白卡纸裁边与去碎点 -> 蜡烛芯/圣诞树星灯锚点定位 -> 防穿模单文件 HTML 打包**，输出双击即开、可发微信、电脑和手机都能稳定体验的立体贺卡！

## 这张立体贺卡自带哪些互动体验？

- **全 Agent 通用 4 层零穿模 3D 纸艺**：无论使用哪家 AI 模型画图，内置“4 层零穿模安全走廊”都能根据图片真实宽高自动避让、翻越 90° 后才弹起立体件并消除一切纸页穿底与重叠，鼠标拖拽或手指滑动任意旋转欣赏都干干净净。
- **双版式同样精致**：
  - **上下翻折版（全新 4:3 横向长方形）**：合上时是规整大气的 4:3 横向长方形封面，向上掀开变身 2:3 宽敞舞台，左前道具、中央人物与右前火漆信封横向舒展排开；
  - **左右横版**：经典书本式左右对折展开，手绘水彩质感细腻优雅。
- **双节日沉浸体验（0 穿帮）**：
  - **生日主题**：机械八音盒自动奏响《生日快乐歌》；左前双层蛋糕插着跳动的暖色烛火——通过 HTTPS 网页链接打开时，翻开卡片自动弹出麦克风授权并放大手机气流信号，轻吹即可灭烛许愿；若在微信直接点本地附件或拒绝授权，则**零报错静默切换为“轻点直灭 + 长按约 1 秒仿真吹气”**，任何手机都稳稳可用。
  - **圣诞主题**：取消蛋糕，左前改为同画风手绘立体圣诞树，**树顶与树冠挂满常亮并柔和闪烁的暖光星星灯**；点击圣诞树或底部“星灯”按钮可触发星光璀璨绽放并漫天飘落冬日雪花；八音盒自动切换为《We Wish You a Merry Christmas》；刺绣祝福信切换为小圣诞树 + `MERRY ~ CHRISTMAS !` 真毛边棉麻刺绣。
- **Apple 极简美学**：遵循清晰、克制、深度与 *Less is More* 留白设计，全程零 Emoji 表情包，单行磨砂胶囊栏无滚动条。

## 给 AI Agent 看的自动安装配置指引（Agent Setup Guide）

> **致正在帮用户配置本 Skill 的 AI Agent：**
> 当用户要求配置本 Skill 时，请按以下 4 步完成安装并立即向用户收集素材：

1. **安装 Skill 目录**：将本仓库完整复制到宿主约定的技能目录（如 `.agents/skills/birthday-popup-card/`、`~/.claude/skills/birthday-popup-card/`、`~/.gemini/config/skills/birthday-popup-card/`），确保 [`SKILL.md`](./SKILL.md) 位于技能目录顶层。
2. **安装唯一轻量 Python 依赖**：确认 Python 3.9+ 后执行 `pip install -r requirements.txt`（仅需 Pillow）。
3. **按自身能力自动分流**：
   - 自带视觉识图 + 生图工具的多模态 Agent：直接进入第 4 步；
   - 纯命令行代码助手：运行 `python scripts/ai_redraw.py --check-env`，若未配置密钥则引导用户通过 `.env.example` 安全写入本机 `.env`（绝不要让用户在聊天中发送明文密钥）。
4. **立刻启动引导**：按 [`SKILL.md`](./SKILL.md) 第一步向用户确认节日主题、版式并索要素材与祝福语（提供模板填空或自写二选一）。
