# 手绘 3D 立体弹出式节日贺卡 Skill (`birthday-popup-card` · V8 云端直装保真版)

专为**自带看图与生图能力的多模态 AI 助手（千问、豆包、Antigravity 等）**打造的 3D 立体贺卡定制技能包，支持 **生日 / 圣诞双主题** 与 **上下翻折 4:3 横向长方形 / 左右横版双版式**。

## 核心特点（优先保证千问 / 豆包等云端软件原版直装、零弹窗、零走样）
- **单一纯净路线，零弹窗秒过审查**：仅 **7 个纯文本文件**（零二进制大图、零联网脚本、零 API 密钥配置），彻底消除云端软件的“多版本选择弹窗”与高风险扫描阻塞。
- **100% 锁死正宗 3D 母版特效**：将经过全量回归验证的 3D 纸艺母版拆分为 4 个纯文本小分片（`resources/shell_p1.css`、`shell_p2.html`、`shell_p3.js`、`shell_p4.js`），由零联网纯本地脚本 `scripts/pack_card.py` 一键拼接输出单文件 HTML，严禁平台现场重写网页导致特效失真。
- **核心互动体验完整保留**：
  - 两段式零穿模 3D 纸艺（纸页先翻平落位，4 层立体纸雕再沿折线长起，小屏拖拽零裁边）；
  - 三层谐波 + 防破音动态限幅 + 峰值安全余量机械八音盒（生日《生日快乐歌》/ 圣诞《We Wish You a Merry Christmas》）；
  - 生日翻开前 5 秒预授权 + 已授权老访客零等待重开 + 1024 点宽带气流吹蜡烛 + 轻点/长按 1 秒兜底；
  - 圣诞树 Alpha 实体内芯防悬空常亮闪烁星灯 + 点击星光绽放飘雪；
  - 升级版高仿真纯代码手工毛边棉麻刺绣信（不靠外部大图即可呈现粗纺亚麻织纹与毛边质感，手机端可滑动编辑，超长文布内滑动，独立 `cardId` 防串词）。
