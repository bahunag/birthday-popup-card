# 立体弹出式手绘节日贺卡生成 Skill (`birthday-popup-card`)

一个开箱即用、可放进任意支持 Agent Skill 的 AI 工具中运行的通用 **3D 立体贺卡定制技能包**，现已全面支持 **生日贺卡 / 圣诞贺卡双主题** 与 **左右横版 / 上下翻折 4:3 横向长方形双版式**！

只要把您的 GitHub 仓库链接发给任意 AI 助手并说 **“帮我配置这个 Skill”**，配置完成之后，它会立刻发一条简洁消息与您确认主题、版式并收集素材：
1. **节日主题**：生日贺卡 ／ 圣诞贺卡；
2. **贺卡版式**：上下翻折（标准 4:3 横向长方形矩形贺卡）／ 左右横版 ／ 两版都做；
3. **封面风格参考图**：任意喜欢的画风参考图（横图、竖图都不影响，后台自动提取画风并**重新绘制一张全新节日封面**，绝不直接贴原图）；
4. **中央主角真人照片**：保留五官、发型、衣服与神态动作，用封面同款画风重绘成立体手绘人物；
5. **祝福语（二选一）**：
   - **选项一（用现成模板）**：套用生日或圣诞专属模板，只需填抬头称呼、落款署名与可选的 1~2 句灵活心里话；
   - **选项二（自己写）**：直接发来或上传您自己写的完整祝福语。

随后 AI 助手会在独立工作目录中采用**两批并行重绘**（减少排队等待），完成去杂点刀模裁边、蜡烛芯/圣诞树星灯定位与两段式零穿模单文件 HTML 打包，输出双击即开、可发微信、电脑和手机都能稳定体验的立体贺卡！

## 核心互动与真机体验亮点

- **全 Agent 通用两段式 0 穿模 3D 纸艺**：阶段 1 纸页率先翻平停稳 -> 阶段 2 立体纸雕平滑长起，任意翻页中间帧与拖拽斜视角 0 穿模；每张卡自带独立 `cardId` 隔离本地存储，同网站多张贺卡互不串改祝福语。
- **针对手机 50% 日常音量调校的饱满八音盒**：三层温暖谐波 + 防破音动态限幅保护，在手机日常 50% 音量下同样清脆响亮、开满 100% 不破音，且翻开前中后音量全程一致。
- **生日版翻开前预授权 + 防卡死零报错兜底**：点击封面后卡片先保持合上，优先完成麦克风授权（带 5 秒超时防内置浏览器卡死），点完允许或拒绝后再完整翻开卡片从头播放音乐，绝不打断惊喜；拒权或微信本地附件下静默零报错自动切换为“轻点直灭 + 长按约 1 秒仿真吹气”。
- **圣诞版常亮闪烁星星灯树（0 穿帮）**：严格隔离蛋糕素材，左前改为手绘立体圣诞树，基于树冠实体内芯定位树顶星与树冠星灯（兼容白雪树与分叉树，0 悬空）；点击圣诞树或底部“星灯”按钮绽放星光并漫天飘雪；八音盒切换为《We Wish You a Merry Christmas》；刺绣信切换为圣诞小树 + `MERRY ~ CHRISTMAS !`。
- **手机端丝滑上下滚动编辑信件**：整个刺绣信件与编辑弹窗原生支持单指上下滑动，点击输入框自动滚入视口中央，弹出输入法键盘也能顺手点到“保存”按钮。
- **轻量化极速配置**：内置棉麻底图采用逐像素一致的无损 WebP 减重近半，精简核心指令、延迟环境检查、支持两批并行出图与仅改祝福语 1~2 秒秒重打。

## 给 AI Agent 看的极速安装配置指引（Agent Setup Guide）

> **致正在帮用户配置本 Skill 的 AI Agent：**
> 1. 将本仓库完整复制到宿主约定的技能目录（确保 [`SKILL.md`](./SKILL.md) 位于顶层）；
> 2. **不要在首次回复前阻塞执行 `pip install` 或 `--check-env`**，直接按 [`SKILL.md`](./SKILL.md) 第一步发短消息收齐素材；
> 3. 真正运行打包脚本前用 `python -c "import PIL" || pip install -r requirements.txt` 懒检查依赖；自带生图工具时跳过 API 密钥检查；
> 4. 按两批并行顺序出图（第 1 批封面+人物，第 2 批内页+拱门+道具）；若用户仅改祝福语，直接复用已有原图重跑 `build_card.py`。
