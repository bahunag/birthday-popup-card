# 手绘 3D 立体弹出式节日贺卡 Skill (`birthday-popup-card` · V8.3 云端直装高保真版)

专为**自带看图与生图能力的多模态 AI 助手（千问、豆包、Antigravity 等）**打造的 3D 立体贺卡定制技能包，支持 **生日 / 圣诞双主题** 与 **上下翻折 4:3 横向长方形 / 左右横版双版式**。

## 设计目标与核心特点
- **精简纯文本结构，兼顾云端直装与高画质**：仅包含 **7 个核心纯文本文件**（零外部二进制大图、零 Base64 密文、零联网脚本、零 API 密钥），保持快速安装与生图节奏的同时，恢复高密度视觉拆解、防写真拼贴约束与出图硬自检，追平完整原版画质。
- **实拍级 3D 高度场棉麻刺绣信本地实时织造**：`scripts/pack_card.py` 在本地打包时用纯 Pillow 现场合成带活纱线微扭曲 3D 高度场法线打光、宏观枕头卷边软皱、柔和针眼勒凹与饱满拧股粗棉绳锁边、外缘柔白棉絮毛边且零脏黑边零刷子刺的亚麻底布（耗时约 0.12 秒、仅约 52 KB WebP），配合 `#fray-edge-filter` 咬布滤镜与 `#352c23` 暖炭棕正片叠底压印，无需内置 1.46 MB 大图即可达到实拍布贴质感，支持手机端滑动编辑与超长文布内滚动。
- **锁定正宗 3D 母版拼接输出与真机吹蜡烛重构**：
  - 两段式零穿模 3D 纸艺（纸页先翻平落位，4 层立体纸雕再沿折线长起，小屏拖拽零裁边）；
  - 三层谐波 + 防破音动态限幅 + 峰值安全余量机械八音盒（生日《生日快乐歌》/ 圣诞《We Wish You a Merry Christmas》）；
  - **宽带频谱平坦度真机吹蜡烛引擎**（兼容手机硬件高通滤波与正常距离呼气，带防底噪拉爆锁与静音拉流节点，外放八音盒/人声 0 误灭）+ 抗花环干扰烛芯识别；
  - 圣诞树 Alpha 实体内芯防悬空常亮闪烁星灯（含偏心歪斜树尖适配与无安全点安全隐藏）+ 点击星光绽放飘雪。
