# 手绘 3D 立体弹出式节日贺卡 Skill (`birthday-popup-card` · V8.5 极速稳健版)

专为**自带看图与生图能力的多模态 AI 助手（千问、豆包、Antigravity 等）**打造的 3D 立体贺卡定制技能包，支持 **生日 / 圣诞双主题** 与 **上下翻折 4:3 横向长方形 / 左右横版双版式**。

## 设计目标与核心特点
- **极致轻量纯文本，云端直装不卡壳**：仅包含 **7 个核心纯文本文件**（总明文压缩至约 `90.6 KB`、降幅 `35.7%`，**全文件 0 反斜杠**彻底消除 JSON 转义纠结，内置 2 批防截断装包指引；零外部二进制大图、零联网脚本、零 API 密钥）。
- **纯前景 100% 精准蜡烛定位（零误伤白奶油蛋糕）**：`scripts/pack_card.py` 在加上 300g 米白卡纸刀模边前直接保留纯主体前景遮罩（对已带刀模边的透明图采用外缘 15px 受限剥离），配合顶部最高峰与中轴居中加权精准锁定顶部单蜡烛黑棉芯；蛋糕重绘提示词彻底移除木椅/花环干扰物，避免弱模型生图导致火苗错位。
- **暖沙原麻 3D 高度场棉麻刺绣信本地实时合成**：纯 Pillow 现场织出带斜粒微纹理、云斑揉皱、厚鼓滚边凹槽、手工斜倾粗白棉绳锁边与手撕短棉絮的亚麻底布（520×710，零外部大图），支持手机端全层滑动编辑与超长文布内滚动。
- **真人友好双通道吹蜡烛 + 预览壳精准提示**：
  - 两段式零穿模 3D 纸艺与防破音三层谐波机械八音盒（生日《生日快乐歌》/ 圣诞《We Wish You a Merry Christmas》）；
  - **双通道宽带 SFM 吹气引擎**（`65~680Hz` 主力贴麦低中频气流 + `950~3600Hz` 高通麦呼气，采用对数 dB 加法门槛与真实环境基线校准，在 Playwright + Web Audio 实测中贴麦低频吹、常规吹、高通麦吹与空调房叠加吹均 0.6~0.8 秒稳灭，静音、八音盒、180Hz 嗡声、440Hz 四音和弦与持续空调底噪 0 误灭）；
  - 顶部音量条实时跳动反馈收音状态；在千问 `share.my.cn` 等未开放 `allow="microphone"` 的跨域嵌套预览壳中明确提示长按吹灭或下载 HTML 后用浏览器打开；
  - 圣诞树 Alpha 实体内芯防悬空常亮闪烁星灯 + 点击星光绽放飘雪。
